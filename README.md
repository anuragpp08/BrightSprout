# Bright Sprout

Home page for the Bright Sprout charitable trust. English copy lives in `content/en`. Hindi and Marathi can be added later as matching dictionaries.

## Run locally

Install [Node.js 22 or newer](https://nodejs.org) (current LTS is fine), then:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

The app is a standard Next.js project and can be imported into Vercel. Set the production site URL in `content/en/site.ts` before launch.
